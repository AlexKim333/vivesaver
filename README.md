# VibeSaver.ai — 50% 반값 토큰절약형 바이브 코딩 에이전트 양판점

> **"사용자는 오직 바이브 코딩(Vibe Coding)에만 집중하세요. 비용은 50% 줄이고, 속도는 3배 빨라집니다."**

---

## 1. 프로젝트 개요 (Executive Summary)

**VibeSaver.ai**는 고성능 LLM(Claude 3.5 Sonnet / Claude 3 Opus / Gemini Pro 등)을 활용한 코딩 에이전트 사용 시 발생하는 **막대한 토큰 비용과 컨텍스트 제한 문제를 완벽하게 해결하는 차세대 AI 코딩 미들웨어 및 에이전트 플랫폼**입니다.


### 핵심 가치 제안 (Value Proposition)
- **사용자(Developer/Team) 혜택**: 기존 AI 에이전트 대비 **토큰 비용 50% 즉시 절약 + 응답 속도(TTFT) 3배 향상**
- **Zero-Config Vibe Coding**: 사용자는 복잡한 프롬프트 엔지니어링이나 `.cursorrules`, 토큰 다이어트 규칙을 신경 쓸 필요 없이 **평소 하던 대로 자연어로 편하게 코딩**하면 됩니다.
- **비즈니스 마진 구조 (Token Cost Arbitrage)**: 내부적으로 **계층형 KV 캐싱 + 시맨틱 델타 엔진**을 구동하여 실제 API 원가를 10~20% 수준으로 절감하고, **30~40%의 기술적 수익 마진**을 창출합니다.

## 2. 핵심 아키텍처 및 3대 원천 기술

```
+-----------------------------------------------------------------------------+
|                     [ User IDE / Vibe Coding Client ]                       |
|        (Cursor / VSCode / Web IDE - 자연어 날 것 그대로 질의)                  |
+-----------------------------------------------------------------------------+
                                      │
                                      ▼ (API Router / Middleware Gateway)
+-----------------------------------------------------------------------------+
|                     [ Smart Token-Saving Engine ]                           |
|                                                                             |
|  1. Layered KV Cache Manager (계층형 컨텍스트 캐싱)                         |
|     - 프로젝트 아키텍처, 룰셋, 핵심 의존성 코드를 상시 메모리 캐싱                  |
|     - 입력(Read) 토큰 비용 90% 할인 적용 (1/10 가격)                        |
|                                                                             |
|  2. Semantic Delta Engine (AST 기반 의미론적 델타 처리)                     |
|     - 파일 전체 전송 금지 -> 기능 변경이 있는 AST 시맨틱 Diff만 추출하여 Append |
|     - 캐시 무효화(Cache Invalidation) 원천 차단                              |
|                                                                             |
|  3. Patch-Only Output Controller (출력 델타 제어기)                         |
|     - LLM 응답을 Search & Replace Diff 패치로만 제한                           |
|     - 출력(Output) 토큰 비용 80~90% 절감 및 수 초 이내 응답                  |
+-----------------------------------------------------------------------------+
                                      │
                                      ▼ (최소 토큰 & 최단 지연 시간)
+-----------------------------------------------------------------------------+
|              [ High-End LLM Endpoints (Opus / Sonnet / Gemini) ]            |
+-----------------------------------------------------------------------------+
```

### ① 계층형 컨텍스트 캐싱 (Layered KV Caching)
- **Layer 1 (Static Layer)**: 프로젝트의 불변 영역(전체 아키텍처, 문서, DB 스키마, 기본 라이브러리)을 KV 캐시로 스냅샷하여 상시 유지. **매 질문마다 90% 할인된 가격**으로 프로젝트 전반을 이해.
- **Layer 2 (Dynamic Layer)**: 사용자의 실시간 작업 및 대화 내용만 뒷부분에 스트리밍으로 덧붙임.

### ② AST 시맨틱 델타 인지 및 처리 (Semantic Delta Recognition)
- 코드가 한 글자 바뀌어도 캐시가 무효화되는 기존 프롬프트 캐싱의 한계를 극복.
- 공백/주석 변경은 무시하고, 실제 의미(Semantic)가 변경된 Git Diff/AST 패치만 **캐시 끝에 Append**하여 토큰 소모량을 1/10로 고정.

### ③ 출력 델타 생성 (Output Patch Generation)
- 파일 전체를 덮어쓰지 않고, 수정되는 타겟 코드 블록만 정확히 치환하는 패치 형태로 출력.
- 답변 생성 시간과 가장 비싼 출력 토큰을 극적으로 단축.

1. **AI 코딩 스마트 프록시 게이트웨이 (Smart API Gateway)**

   - 직군 및 작업별(리팩토링, QA, 보안검사, 아키텍처 등)로 최적화된 저비용/고성능 특화 에이전트 스토어.
3. **B2B 엔터프라이즈 토큰 다이어트 솔루션 (Enterprise SaaS)**
   - 개발 기업 대상 LLM API 비용 50% 절감 보장 및 성과 연동형 솔루션.

## 4. 이 프로젝트에 연결된 AI 모델을 위한 지침 (Model Orientation)

> **이 폴더에 연결된 AI 에이전트(Cursor, Claude, Gemini 등)는 아래 사항을 즉시 인식해야 합니다.**
- 당신은 **"토큰절약형 코딩에이전트(Smart Token-Saving Agent)"** 프로젝트의 핵심 설계 및 개발을 담당하는 AI 파트너입니다.
- 모든 코딩 및 설계 제안 시 **"컨텍스트 캐싱 친화적 파일 구조(Cache-Friendly Architecture)"**와 **"델타 패치 처리(Delta Processing)"** 원칙을 준수해야 합니다.
- 사용자가 복잡한 룰이나 규칙을 신경 쓰지 않도록, 모든 최적화 로직은 **백그라운드 미들웨어(Transparent Middleware)**로 처리되도록 구현합니다.
